📖 Sentinel User Guide

Overview

Sentinel is a comprehensive data collection platform for Euro NCAP DSM (Driver Monitoring System) protocol testing. It helps plan and execute truck journeys with precisely scheduled driver distraction scenarios.

1. Pre-Trip Quiz

  • Fill in required fields (driver code, date, time, vehicle, route, weather)
  • Check the consent checkbox before starting
  • Data is auto-saved to local storage

2. Journey Planner

  • Search for locations by typing - suggestions appear automatically
  • Set date and start time for accurate sun position calculation
  • Enable sun optimization to prefer frontlit/sidelit conditions
  • Click Plan Journey to generate routes with Euro NCAP scenarios
  • Export the plan to use in the Navigator

3. Navigator

  • Load a plan exported from the Planner
  • Click Start to begin navigation with GPS
  • TTS announcements guide the driver:
    • "Approaching scenario" - ~30 seconds before
    • "Start now" - when scenario begins
    • Clear movement and gaze instructions
  • The green bar shows current instructions
  • Test Voice to verify TTS is working

Euro NCAP Scenario Types

  • Short Distraction (VATS): 10s cumulative within 30s window
  • Long Distraction: 3-4s continuous look away
  • Movement Types: Owl (head+eyes), Lizard (eyes only), Body Lean, Tarsier (head only)

Tips

  • Use Chrome for best TTS quality
  • Grant GPS permissions when prompted
  • Keep screen active during navigation
  • Works offline after first load
